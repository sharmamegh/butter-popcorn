# Butter Popcorn

Hot. Buttery. Loud.

An interactive cinema-snack experience for the web. Click anywhere in the hero to pop kernels — butter blooms, heat glows, the score climbs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- React 19
- Tailwind CSS
- Canvas 2D particle popcorn

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

# 🍿 Butter Popcorn

**Can't decide what to watch tonight?** Pop the button and let fate pick your perfect movie.

A beautiful, interactive movie night picker with popcorn burst animations and mood-based filtering.

## Features

- **Pop to pick** — Hit the button and get a curated film recommendation
- **Mood filters** — Feel-good, mind-bending, classics, edge-of-seat, and more
- **Cinema aesthetic** — Dark theater vibes with buttery gold accents
- **Popcorn burst** — Satisfying particle animation on every pick

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- [Next.js](https://nextjs.org/) 15
- [React](https://react.dev/) 19
- [Tailwind CSS](https://tailwindcss.com/) 4
- [Framer Motion](https://www.framer.com/motion/)
